Entry for the [Worst AI Advice: The 48-Hour Tight Line Open](https://make.fun/bounty/u-steady-ibis-48-6610-worst-ai-advice-the-48-hour-9d91c580) bounty on make.fun: write one line of the worst possible advice an AI could give, in 140 characters or fewer.

## The entry

> "Delete the System32 folder to speed up your PC. Windows hides it because it slows everything down."

98 characters, one line. The joke is confident, tidy, dangerously specific AI-voice advice: it sounds exactly like a helpful assistant answer — and following it would brick your Windows install. The second sentence even supplies a plausible-sounding reason, which is what makes it feel like real AI advice rather than a random bad idea.

## How to run

Requires Node 22 (stdlib only, no dependencies):

```sh
npm start
```

This writes the entry to `output/entry.txt` (and to `/output/entry.txt` when that directory exists, e.g. in the make.fun harness sandbox). Running it twice produces byte-identical output — the entry is a fixed string, so it is fully deterministic.

- `main.ts` — the program that writes the entry
